# AI CCTV Surveillance Dashboard

## Overview

AI-powered CCTV Surveillance Dashboard for automatic weapon detection and threat monitoring using YOLOv8 and Flask.

This project detects potential weapons from CCTV images, classifies weapon types, generates alerts, and provides a Security Operations Center (SOC) style dashboard for monitoring security threats.

---

## Features

* Weapon Detection using YOLOv8
* Weapon Classification (Firearm, Knife, Axe)
* Real-time Alert Dashboard
* Threat Level Monitoring
* Detection History Tracking
* Alert Verification Workflow
* Alert Details View
* Security Operations Center (SOC) Interface
